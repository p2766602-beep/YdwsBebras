## 觀察與待辦

1. **PDF文字擷取品質不一**：用 pypdf 直接擷取，2018-2022年PDF乾淨無亂碼；2023-2025年PDF字型缺ToUnicode對照，連字（ti/fi等）會變成亂碼（如 InternaƟonal），且部分年度（2022起）詞間空格遺失需人工補回。翻譯前務必先人工校對，不能直接丟原始擷取文字。
2. **同名/疑似重複待查**：2022的 "Maze" 與2021的 "Maze" 是否為同一題；2024的 "Balloon Machine" (p53) 與 "Balloon machine" (p90) 是否為同一題重複列示，需要開對應頁面人工比對確認。
3. **每年度「Content頁列出的獨立題數」<「6組題數總和」**：代表同一題常被同時放進多個年齡組（例如同一題同時是Group V和VI的其中一題），這點會影響「難度/學習階段」欄位設計——同一 task_uid 可能對應多個 age_group。
4. **2023年度題本結構最完整**：目錄頁直接標出每題在哪些組別是A/B/C哪個難度，其餘年度沒有這個對照，需要另外去內文核對。
